# Support

FaithFull Scholars is an open-source professional network for theological and biblical higher education.

---

## Where to Ask for Help

- **Bug reports**: open a GitHub issue with reproduction steps.
- **Feature proposals**: open an issue describing the scholar, institution or admin workflow, and why it matters (for example, an accreditation, hiring or confessional-fit need).
- **Security issues**: report them privately, as described in [`SECURITY.md`](SECURITY.md). Never use a public issue.

---

## What to Include When Opening an Issue

1. **Operating system and Node version** (`node -v`, `npm -v`)
2. **Commit SHA** or release tag
3. **Which persona** you were using: public visitor, scholar, institution or admin
4. **Exact reproduction steps**, and the test commands if relevant (`npm run test`, `npm run test:e2e`)
5. **Sanitized error output.** Never include keys, passwords, real scholar data, doctrinal statements or institution search data.
