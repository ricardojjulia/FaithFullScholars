# ADR 0001: Scholar Profile Network First

## Status

Accepted

## Context

FaithFull Scholars could become a directory, marketplace, course portal, content library, recruiting tool, or theological social network. Building all of these at once would create unclear scope and slow the first proof of value.

## Decision

The MVP will be a Scholar Profile Network. It will prioritize public scholar profiles, academic portfolio, course showcase, availability signals, institutional discovery, and structured inquiries.

Formal hiring workflows, payments, contracts, endorsements, social feeds, and LMS capabilities are deferred.

## Consequences

Positive:

- Faster MVP.
- Clearer trust and moderation model.
- Stronger data foundation for later marketplace features.
- Easier adoption by scholars because profile value exists before transactions.

Negative:

- Revenue may depend on later institution features.
- Some colleges may still need offline contracting after discovery.
- Marketplace demand must be validated through inquiry behavior before automation.
