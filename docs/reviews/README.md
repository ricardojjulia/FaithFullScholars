# Council Reviews & Synthesis Records

This directory stores outputs generated by the 5-Agent Council during non-trivial development cycles per `improve-software.md`:

- `YYYY-MM-DD-council-review-[N]-synthesis.md`
- `YYYY-MM-DD-council-review-[N]-agent-1-data-api.md`
- `YYYY-MM-DD-council-review-[N]-agent-2-routes-pages.md`
- `YYYY-MM-DD-council-review-[N]-agent-3-ux-shell.md`
- `YYYY-MM-DD-council-review-[N]-agent-4-feature-competitive.md`

All reviews must be committed to git by the **Documenter** before opening pull requests to prevent documentation drift.
