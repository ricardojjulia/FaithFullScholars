## 5. Phase 17 Implementation Details (ADR 0020 & Hardening)

### A. Architectural Decision Record & Domain Engine
- Authored `docs/adr/0020-confessional-common-application-and-applicant-matrix.md`.
- Implemented pure evaluation engine in `lib/postings/applicant-service.ts`:
  - `compileApplicantReport(postingId)`: Aggregates candidate submissions, extracts verified doctoral degrees, validates terminal doctoral ratio per ATS Standard 3, calculates confessional fit scores, and tracks candidate triage status (`under_review`, `shortlisted`, `interviewing`, `offer_extended`, `archived`).
  - `exportApplicantCsv(report)`: RFC-4180 compliant CSV generator with UTF-8 BOM (`\uFEFF`) for Microsoft Excel and committee triage.

### B. User Interface & Search Committee Matrix
- Created `<PostingApplicantMatrix />` in `components/institution/posting-applicant-matrix.tsx`:
  - KPI summary cards (Total Applicants, Terminal Doctorate Ratio with ATS badge, Avg Confessional Fit, Shortlisted/Interviewing count).
  - Status filter tabs (All, Under Review, Shortlisted, Interviewing, Offer Extended, Archived).
  - Candidate triage status updater with persistent optimistic state.
  - Candidate Dossier inspection modal rendering degrees, affirmed confessions, and personal statements.
  - Print-optimized CSS (`@media print`) and 1-click CSV candidate roster export.
- Mounted dedicated search committee view at `app/(institution)/institution/postings/[id]/applicants/page.tsx`.
- Added "Applicant Matrix" navigation button on `/institution/postings` opportunities list.
- Enhanced `app/api/postings/[id]/express-interest/route.ts` with structured Common Application metadata formatting.
