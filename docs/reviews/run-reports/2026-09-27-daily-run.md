## 2. Open Items Identified and Resolved

1. **Stale Local WebServer & Test Concurrency Cleanup**:
   - Identified a long-running, stale `next-server` process from a previous build session bound to port 3845. Terminated the stale instance to ensure clean execution against fresh compilation artifacts.
2. **Playwright WebServer Diagnostics Environment Flag**:
   - Identified that `/dev/status` rendered a 404 in production mode during Playwright runs because `ENABLE_DEV_ROUTES` was not exported in the Playwright `webServer.env` context.
   - Configured `ENABLE_DEV_ROUTES: 'true'` in `playwright.config.ts` and `.env.local` to allow unauthenticated test assertions on the developer diagnostics dashboard.
3. **Client-Side Hydration Race Condition in E2E Language Switcher**:
   - Identified a race condition in `tests/e2e/translation-and-locale.spec.ts` where rapidly clicking the `<LanguageSwitcher />` button before React client component hydration completed caused the click to be lost, resulting in Playwright waiting indefinitely for the dropdown menu items.
   - Hardened dropdown interaction with Playwright's `expect.toPass()` polling retry pattern and added explicit bidirectional (`en` → `es` → `en`) verification on the Course Catalog and Speaking Bureau routes.
